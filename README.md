# My SPA App

React + Supabase 기반 메모 CRUD SPA.

## 기술 스택
- React 18
- React Router
- Supabase
- Framer Motion
- Vite
- CSS

## 주요 기능
- SPA 라우팅
- 목록 / 상세 / 등록 / 수정 / 삭제
- 로딩 / 에러 / 빈 상태 공통 UI
- Controlled Form + 유효성 검증
- 커스텀 훅
- 페이지 전환 애니메이션
- Not Found

## 실행
```bash
npm install
npm run dev
```

## 환경변수
`.env.example`을 참고해 `.env`를 생성:

```env
VITE_SUPABASE_URL=...
VITE_SUPABASE_PUBLISHABLE_KEY=...
```

## Supabase SQL
```sql
create table notes (
  id bigint generated by default as identity primary key,
  title text not null,
  content text not null,
  created_at timestamptz default now()
);
```

## 라우트
- `/`
- `/items`
- `/items/new`
- `/items/:id`
- `/items/:id/edit`
- `/about`
- `*`
